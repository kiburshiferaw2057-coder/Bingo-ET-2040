# BINGO ET — Updated App & New Repository Starter

## Features
- **1–600 Bingo Selector** with range tabs (`1–150`, `151–300`, `301–450`, `451–600`, `All (600)`) and direct number jump.
- **2-Minute (`120s`) Round Cycle** with live minute countdown and automatic next-round reset.
- **75-Ball B-I-N-G-O Board & Winner View** with live called balls, claim button, and winner card breakdown.
- **Birr (`ETB`) Wallet Drawer** with deposit/withdraw simulation, transaction history, and game history.
- **Multilingual UI & Rules** in Amharic (`አማ`), Tigrigna (`ትግ`), and English (`EN`).
