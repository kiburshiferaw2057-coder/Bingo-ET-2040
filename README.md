# Bingo ET (v2)

Android application (**Bingo ET**) built with Kotlin and Jetpack Compose, configured with:
- Official **Bingo ET** receipt accounts (**Kibur Shiferaw Kassa**):
  - **Telebirr:** `0912341486` or `0941705946` (Kibur)
  - **CBE:** `1000058081624` (Kibur Shiferaw Kassa)
  - **BOA:** `82323805` (Kibur Shiferaw Kassa)
- **Card Price:** `10.0` Birr each card, **80%** winner payout share (`0.80`), with Bingo 1020 speed & long-term session persistence (`longTermRoundsPlayed`, `totalWageredBirr`, `totalWonBirr`, `bestStreak`, `currentStreak`, and persisted round/transaction history).
- **Game Modes:** `SHORT_ONE_OR_STAR` (Short 1 Line or 4 Corner Star), `SHORT_THREE_LINE` (Short 3 Line Bingo), and `BINGO_1020_CLASSIC` (Bingo 1020 Style).
- **Theme:** Green with Red mix.
- **Languages:** Amharic (`አማርኛ`), English, Afaan Oromo, and Tigrinya (`ትግርኛ`).
